# 개발 환경 준비

조직에 처음 들어왔을 때 한 번만 하면 되는 준비입니다. 버전은 수업(MSA 실습)에서 쓴 것을 기준으로 맞췄습니다.

## 1. 조직 초대 수락

GitHub 알림이나 메일로 온 `LGCNS-AM06-Final-TEAM4` 초대를 수락합니다. 메일을 못 찾으면 https://github.com/orgs/LGCNS-AM06-Final-TEAM4/invitation 에서 수락할 수 있습니다. 수락하면 `team4` 팀에 들어가고 backend, frontend, config 세 레포에 쓰기 권한이 생깁니다.

## 2. 설치할 도구

| 도구 | 버전 | 쓰는 곳 |
| --- | --- | --- |
| Git | 최신 | 전체 |
| JDK | 21 (Temurin 권장) | backend |
| IntelliJ IDEA | Community 또는 Ultimate | backend |
| Node.js | LTS | frontend |
| VS Code | 최신 | frontend |
| Docker Desktop | 최신 | MariaDB, Redis, Kafka 같은 미들웨어를 로컬에서 띄울 때 |

설치가 끝나면 터미널에서 버전을 확인합니다.

```bash
git --version
java -version
node -v
docker -v
```

`java -version`이 21이 아니면 IntelliJ에서 File > Project Structure > SDK를 21로 맞춰 주세요. Lombok을 쓰므로 Settings > Build > Compiler > Annotation Processors에서 Enable annotation processing을 켭니다.

## 3. 레포 받기

세 레포를 한 폴더 아래에 받아 두면 편합니다.

```bash
mkdir retail-final
cd retail-final
git clone https://github.com/LGCNS-AM06-Final-TEAM4/backend.git
git clone https://github.com/LGCNS-AM06-Final-TEAM4/frontend.git
git clone https://github.com/LGCNS-AM06-Final-TEAM4/config.git
```

커밋 작성자가 GitHub 계정과 이어지도록 이름과 이메일을 GitHub에 등록된 것으로 맞춥니다.

```bash
git config --global user.name "GitHub 아이디"
git config --global user.email "GitHub에 등록한 이메일"
```

줄바꿈은 레포의 `.gitattributes`가 LF로 맞춰 주므로 따로 설정하지 않아도 됩니다.

## 4. 비밀 정보

API 키, DB 비밀번호, JWT 키는 커밋하지 않습니다. 각 레포에 `.env.example`이 생기면 복사해서 `.env`를 만들고 값을 채웁니다. 값은 팀장이나 클라우드 담당에게 따로 받습니다.

## 5. 지금 레포 상태

주제가 확정되기 전이라 서비스 코드는 아직 없습니다. 주제와 서비스 분리가 정해지면 backend에 Gradle 멀티 모듈 골격(discovery, gateway, config, ai, common)과 docker-compose를, frontend에 React + Vite 프로젝트를 먼저 올립니다. 그 전까지는 [보드](https://github.com/orgs/LGCNS-AM06-Final-TEAM4/projects/1)에 이슈를 정리하는 작업부터 합니다.

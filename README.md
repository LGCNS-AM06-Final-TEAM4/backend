# AI 리테일 CS 코파일럿

온라인 셀러가 매일 직접 읽고 분류하고 답하는 고객 문의와 리뷰를 AI가 대신 분류하고, 상품 정보와 정책을 근거로 답변 초안을 만들어 주는 셀러 운영 서비스입니다. 공개 리뷰·문의 데이터로 시작해 정답셋 기준 "개선 전후 숫자"로 효과를 보여 주는 것이 목표입니다.

LG CNS AM Inspire Camp 6기 최종 프로젝트 4조 (리테일, 멘토 이상헌)

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 문의 자동 분류 | 배송·교환·사이즈·불량 등 유형과 긴급도를 판정하고, 확신도가 낮으면 상담원 대기열로 보냅니다 |
| 근거 기반 답변 초안 | 상품 정보·FAQ·반품 정책을 RAG로 찾아 출처와 함께 답변 초안을 만듭니다 |
| 주문·배송 조회 에이전트 | 주문 API를 도구로 호출해 "내 주문 언제 와요?" 같은 질문에 답합니다 |
| 리뷰 인사이트 | 리뷰를 장점·단점·반품 사유로 요약하고 근거 리뷰를 연결합니다 |
| 셀러 대시보드 | 상담원 확인 대기열, AI 정확도·처리 시간 지표를 보여 줍니다 |

## 기술 스택

| 영역 | 기술 |
| --- | --- |
| Frontend | React, TypeScript |
| Backend | Spring Boot (주문·문의 API) |
| AI | FastAPI, LLM API, LangGraph, pgvector |
| DB | PostgreSQL + pgvector |
| Infra | AWS (ECS, RDS, S3), Docker, GitHub Actions |

## 폴더 구조

```
frontend/   셀러 대시보드, 고객 채팅 화면
backend/    주문·문의 업무 API
ai/         분류·RAG·에이전트 AI 서비스
infra/      docker-compose, 배포 설정
data/       정답셋, 전처리 스크립트 (원본 데이터는 커밋하지 않음)
docs/       협업 규칙, 설계 문서
```

세 서비스를 한 레포에서 관리합니다. API 규격이 바뀔 때 FE·BE·AI를 한 PR에서 같이 고칠 수 있고, 이슈와 Projects 보드가 한곳에 모이기 때문입니다.
